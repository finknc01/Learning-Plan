# Labs

Hands-on exercises that demonstrate practical infrastructure capability.

Each substantial lab should include:

1. objective
2. architecture / environment
3. prerequisites
4. implementation
5. validation
6. failure testing
7. troubleshooting
8. lessons learned
9. production considerations

Use [`../templates/lab-template.md`](../templates/lab-template.md) as the starting point.

## Planned lab categories

- Ubuntu / Rocky Linux administration
- storage and host networking
- NVIDIA driver / CUDA installation
- GPU validation and DCGM diagnostics
- Docker and GPU containers
- Kubernetes fundamentals
- NVIDIA GPU Operator
- Slurm controller / compute nodes
- Slurm GPU scheduling
- Prometheus / Grafana / DCGM Exporter
- Ansible and Python infrastructure automation
