# Labs

This directory is for **small exercises, cross-project experiments, and reusable demonstrations** that support the 52-week learning plan.

The ten substantial story-driven portfolio labs live in dedicated repositories and are indexed in [`../portfolio/README.md`](../portfolio/README.md). Their timing is mapped in [`../roadmap/lab-schedule.md`](../roadmap/lab-schedule.md).

Use this directory when an exercise is useful evidence but does **not** need its own project identity—for example a one-off command study, a small Bash/Python experiment, a comparison table, or a focused validation procedure.

## Small-lab standard

A useful exercise should capture enough context that it can be understood later:

1. objective / question
2. environment
3. expected behavior
4. action or experiment
5. evidence / result
6. failure or surprise, if any
7. lesson learned
8. exact restart point if unfinished

Use [`../templates/lab-template.md`](../templates/lab-template.md) as a starting point where useful.
