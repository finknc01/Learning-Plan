# Portfolio Project Index

This directory links the larger integrated projects produced during the 52-week learning plan.

Small exercises remain in this repository. A project should generally receive its own repository when it demonstrates a complete system or can support a substantial technical interview discussion.

## Planned standalone projects

### GPU Infrastructure Lab
Linux GPU host deployment, NVIDIA driver/CUDA validation, topology analysis, DCGM diagnostics, and troubleshooting.

### Kubernetes GPU Platform
Kubernetes cluster with NVIDIA GPU Operator, GPU discovery/scheduling, workload deployment, telemetry, and failure recovery.

### Slurm / HPC GPU Cluster
Slurm controller and compute-node environment with GRES-based GPU scheduling, job submission, monitoring, and troubleshooting.

### AI Infrastructure Observability
DCGM Exporter, Prometheus, Grafana, dashboards, alerts, and an incident-style case study.

### Secure / Private AI Infrastructure
Infrastructure-focused security design connecting prior privacy-preserving ML experience with isolation, access control, network segmentation, secrets, telemetry, and operational controls.

## Project standard

Each linked project should clearly show:

- problem and scope
- architecture
- implementation
- automation/configuration
- validation evidence
- failure testing and recovery
- design tradeoffs
- production considerations
