# Scripts and Automation

Automation developed during the learning plan.

## Planned areas

- Bash administration scripts
- Python infrastructure utilities
- Ansible playbooks and roles
- configuration validation
- telemetry parsing
- repeatable environment setup

Scripts should include concise usage documentation and avoid embedding secrets, employer-specific details, or environment-specific credentials.

When a script becomes large enough to represent a standalone project, it may move into its own repository and be linked from the portfolio index.
