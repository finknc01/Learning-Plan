# Roadmap

This directory keeps the public, portfolio-oriented view of the 52-week learning plan.

The detailed canonical checklist remains in Notion. GitHub is intentionally organized around **what is active now, when the standalone labs are used, and what evidence has been produced**.

## Start here

- [`current-sprint.md`](current-sprint.md) — the one primary mission, supporting concept, and evidence target that are active now.
- [`execution-system.md`](execution-system.md) — the focus-friendly study workflow: Now/Next/Later, session sizes, minimum viable week, breadcrumbs, and no catch-up debt.
- [`lab-schedule.md`](lab-schedule.md) — where all ten standalone story-driven labs enter and re-enter the 52-week curriculum.

## Milestone snapshots

As milestones are reached, add concise evidence-oriented summaries such as:

- `week-06-linux-gate.md`
- `week-14-gpu-administration.md`
- `week-20-ai-networking-and-rack.md`
- `week-24-gpu-containers.md`
- `week-30-kubernetes-gpu.md`
- `week-34-slurm-gpu.md`
- `week-38-observability.md`
- `week-40-automation.md`
- `week-42-integration.md`
- `week-44-portfolio-gate.md`
- `week-52-final-assessment.md`

Each milestone should summarize:

1. what was learned
2. what was demonstrated hands-on
3. which standalone labs contributed evidence
4. artifacts produced
5. failures encountered and how they were diagnosed
6. what remains weak or modeled rather than measured
7. the next highest-value gap

The roadmap is not meant to duplicate every Notion checkbox. It is the readable public story of progress through the system.
